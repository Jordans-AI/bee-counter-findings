Takeaways

  • The density ordering C1 < C2 < C3 < C4 is real and measurable: simultaneity and entry rate both increase toward C4. This is the quantitative basis for the per-camera recall ordering reported throughout the project, previously asserted only from visual inspection.
  • Same-frame entries put a hard ceiling on per-frame-cluster counting that no parameter tuning can lift — closing the last recall gap (esp. C4) needs per-bee instance separation, consistent with the documented fine-tune path.
  • The GT is a ballpark, not a precise target (labeler's own caveat): treat the count band as the primary signal and temporal F1 as secondary, exactly as the scoreboard and robustness analyses do.
