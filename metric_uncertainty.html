Metric uncertainty — bootstrap 95% CIs on the published P/R/F1

Every headline number in this project is a point estimate against a GT the reports describe as approximate. This attaches a nonparametric bootstrap 95% CI to those points so the recurring guardrail decision — "no combo beats the shipped F1 by more than a few hundredths, and chasing that against noisy labels is overfitting" — has a number behind it. The resample is at the event level: the production matcher (compare_to_gt._greedy_match_frames, ±15f) labels each prediction TP/FP and each GT entry TP/FN; predictions are resampled with replacement for precision and GT entries for recall, 2000× under a fixed seed. Built only from committed data (tests/fixtures/scoreboard_golden.json + the manual GT) — no video, GPU, or caches — and a gate asserts each point F1 reproduces the scoreboard before its CI is shown.

Findings

  1. The F1 CIs are wide — 0.12–0.31, roughly ±0.10. With only 40–75 labelled entries per camera, the bootstrap 95% interval on F1 is wide enough that a method scoring 0.78 and one scoring 0.76 are statistically indistinguishable: the few-hundredths gaps the nightly sweeps chase are far inside the label-noise band. This is the quantitative justification for every "shipped config is the plateau pick, no change" decision — the measurement cannot resolve a sub-0.05 F1 difference on this much GT.

  2. The method choice splits cleanly by density. On the sparse cameras the paired ΔF1 CI includes 0 — C1 [-0.10, +0.13] (prob 0.65) and C2 [-0.00, +0.21] (prob 0.97) — so absorption's apparent temporal-F1 edge over motion is within noise there; the case for absorption on C1/C2 rests on its count ratio (in-band vs motion's C2 under-count, see scoreboard.md) and spatial localisation (spatial_validation.md), not on F1. On the dense cameras the gap is significant — C3 [+0.16, +0.45] and C4 [+0.48, +0.81], both prob 1.00 — absorption genuinely and reliably beats motion exactly where motion's signal structurally fails (the crowded/grassy entrances with no clean dark-notch descent). So the headline "absorption beats motion everywhere" is two distinct claims: a count improvement on the sparse cameras and a significant F1 improvement on the dense ones.

  3. Recall CIs are wider than precision CIs where precision is near 1.0 (the absorption methods): a high-precision method has little room to vary on the prediction side, so its F1 uncertainty is dominated by recall — consistent with the structural recall ceiling quantified in error_analysis.md / gt_characterization.md.

No config change follows (the intervals confirm the shipped configs, they do not point to a better one). The value is a calibrated uncertainty for the research-paper results section. Reproduce: uv run --no-sync python scripts/metric_uncertainty.py.
