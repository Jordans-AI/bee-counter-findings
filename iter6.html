6.1 — Counter implementation

src/beecounter/count/state_machine.py. Tests: tests/test_state_machine.py — 7/7 pass.

API:

counter = BandStateMachineCounter(line, band_px=25, dwell_frames=3, min_track_len=5)
for frame_idx, track in stream:
    counter.update(track.id, frame_idx, track.centroid)
events = counter.events()

State machine per track: - OUTSIDE : sd < -band_px/2 - IN_BAND : -band_px/2 <= sd <= +band_px/2 - INSIDE : sd > +band_px/2

Valid IN: OUTSIDE → IN_BAND → INSIDE, then dwell ≥ dwell_frames consecutive frames in INSIDE. Valid OUT is the mirror. Per-lap dedup caps each track at one IN and one OUT per traversal cycle. Tracks with fewer than min_track_len observations never emit.

Test coverage: - Straight outside→inside crossing (dwell=3): 1 IN. - Reverse inside→outside crossing (dwell=3): 1 OUT. - Hover oscillating between OUTSIDE and IN_BAND (never INSIDE): 0 events. - Two full laps (OUT→IN→OUT→IN): 3 events (in, out, in) — per-lap dedup allows re-emit after a full cycle. - Track shorter than min_track_len: 0 events. - Insufficient dwell (2 inside frames, dwell=5): 0 events. - events() accessor returns chronological list.

Why the standalone loses on C2 and C4

C2's judge totals are 0/0 (no judged crossings). The Phase 2 hysteresis counter coincidentally emits 0/0 and scores 1.000. The state machine emits 2 phantom IN and 6 phantom OUT, dragging C2 to 0.700. These are real MOG2 detection artifacts (shadows / leaf movement near the lip) that pass the tracker's min_hits=20 gate and complete a full geometric traversal of the 40-pixel band over their lifetime — temporal hysteresis with hysteresis_frames=18 catches these because it needs 18 consecutive frames on the new side, which fragmented tracks can't deliver. The state machine doesn't have that long-tail filter.

C4's judge totals are 2/5. Phase 2 hysteresis emits 2/2 (under-counts OUT, scores 0.750). State machine emits 4/4 (over-counts IN, mis-counts OUT, scores 0.650). The 4 IN events at C4 are again MOG2 detection artifacts on the busy landing-board.

Did spatial hysteresis break the plateau?

No. The mixed iter 6 mean is 0.775 with min-clip 0.550 — bit-for-bit identical to iters 1, 3, 4, and 5. The state machine standalone is worse (0.675) than the Phase 2 baseline (0.775) because it lacks the long-tail track-length filter that Phase 2's hysteresis counter implicitly provides via hysteresis_frames=18 on C2. On C1 and C3 it ties; on C2 and C4 the hysteresis counter wins. Spatial hysteresis is mathematically distinct from temporal hysteresis, but on this detector output stream it identifies the same set of plausible bee crossings — plus a few extra MOG2 artifacts on quiet scenes where the temporal filter would have rejected them. The 0.775 / 0.550 plateau is now confirmed across six iterations spanning every distinct counter mechanism in the techniques bench. The bottleneck is the per-frame detection signal on C3 and C4, not the counter algorithm.
