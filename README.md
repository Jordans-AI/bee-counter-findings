# Bee-entry counting — findings & reports

A static, read-only mirror of the bee-counter project reports — open it in a browser,
no install required:

### → https://jordans-ai.github.io/bee-counter-findings/

Counting honeybee **entries** into four hive entrances from camera footage, and asking
whether hives in different orchards differ in how busy they are.

The interactive debug viewer (video scrubbing, frame labeling) runs locally from the
main project repo — this site is the shareable read-only slice.

> Generated from the project repo by `scripts/build_static_site.py` — do not hand-edit.
